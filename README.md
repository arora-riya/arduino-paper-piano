## arduino-paper-piano

Made this as Applied-Electronics project in first year of my B.Tech. Contributors: Contributors: [Paras Bedi](https://github.com/ParasBedi298), [Riya Arora](https://github.com/arora-riya), [Rishab Bairi](https://github.com/RishabB54), [Rohan Chaudhary](https://github.com/RohanChaudhary1805)

- Different keys (pencil shading, since graphite is a conductor) when touched cause the buzzer to produce different frequencies, the corresponding LED to glow and indication on the 4-digit 7-segment display. This happens as the electronics component in relevant circuit changes its mode of operation which causes the current to flow.
